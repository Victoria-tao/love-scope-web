# 性格契合度 · 网页版（H5）

纯静态网页小程序，无需构建、无需服务器即可本地运行，双击即可打开。
保留了你此前全部功能设计：星座·属相·生日·八字 情感配对、趣味卡牌、深度匹配PRO、性格速配（MBTI）、个人解读、每日日历（黄历）、MBTI测试、全套结果卡片生成。

## 如何打开

直接双击本目录下的 `index.html`，或拖进浏览器（推荐 Chrome / Edge / Safari）。
页面以手机竖屏布局呈现，在电脑浏览器里按 F12 打开开发者工具、切换到手机模拟视图效果最佳。

## 目录结构

```
love-scope-web/
├── index.html          # 入口页面（双击打开它）
├── css/style.css       # 全部样式
├── js/
│   ├── app.js          # 路由 + 全局工具 + 画布绘制（分享卡/雷达图）
│   ├── data/           # 全部数据与计算引擎（星座/属相/生辰/星盘/卡牌/MBTI/黄历）
│   └── pages/          # 各功能页面
│       ├── home.js            主页
│       ├── matching.js        情感契合度（星座·属相·生日·八字）
│       ├── result.js          情感契合度结果 + 分享卡
│       ├── tarot.js           趣味卡牌（选维度 + 抽 1/3 张）
│       ├── tarot-result.js    卡牌结果 + 综合总结卡片
│       ├── pro.js             深度匹配 PRO（六维输入）
│       ├── pro-result.js      PRO 六维雷达结果 + 分享卡
│       ├── mbti-matching.js   性格速配（MBTI 双人）
│       ├── mbti-result.js     性格速配结果 + 总结卡片
│       ├── mbti-test.js       MBTI 16 题测试
│       ├── personal.js        个人解读（星座/属相/MBTI/流年 + 总结卡片）
│       └── daily.js           每日日历（黄历 + 星座属相运势 + 任意选日）

```

> 图片资源（塔罗牌、MBTI 猫咪、五行背景、首页主视觉）沿用原小程序目录 `../love-scope/`，
> 因此 **`love-scope` 和 `love-scope-web` 两个文件夹要放在同级目录**（都在 new-chat-2 下），不要单独移动其一。

## 所有功能一览

| 入口 | 功能 |
|---|---|
| 情感契合度 | 星座/属相/生日/出生时间/城市 任意填写；双方填=缘分配对，只填一方=个人年度情感状态；填全可出上升星座+行星相位 |
| 趣味卡牌 | 情感/事业/健康/朋友/家庭/灵性 6 维度可叠加，抽 1 或 3 张，正逆位 + 分维度指引 + 综合总结卡 |
| 深度匹配 PRO | 星座×属相×生辰×星盘×年度×卡牌 六维加权，六维雷达 + 深度报告分享卡 |
| 性格速配 | MBTI 双人 4 维匹配 + 结果总结卡片 |
| 个人解读 | 星座/属相/MBTI/流年 综合解析 + 猫咪人格图 + 总结卡片下载 |
| 每日日历 | 黄历（宜忌/冲煞/吉凶神）+ 星座属相运势 + 自由选任意日期 |
| MBTI 测试 | 16 题测出人格，16 种猫咪人格形象 + 报告卡片 |

## 上线到公网（可选）

1. 把 `love-scope-web` 和 `love-scope` 两个文件夹一起上传到任意静态托管（GitHub Pages / Vercel / Netlify / 腾讯云 COS + CDN 等），保持相对路径不变。
2. 打开站点首页即可使用，无需后端。
3. 之后要改内容：直接编辑 `js/data/`（文案/数据）或 `js/pages/`（交互/排版），改完刷新即生效，上传覆盖即可。
