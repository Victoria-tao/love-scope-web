## 使用说明

### 在小程序中引用

在 WXML 中使用 `<image>` 标签引用本地图片：

```xml
<!-- 配对结果插画背景 -->
<image class="pair-bg" src="/assets/illustration/pair-themes/01_chixia_fire-fire.png" mode="aspectFill"></image>

<!-- 塔罗牌面 -->
<image class="tarot-card" src="/assets/illustration/tarot-cards/06_lovers.png" mode="aspectFit"></image>
```

在 JS 中根据配对主题动态选择图片：

```js
const THEME_IMAGES = {
  '火火': '/assets/illustration/pair-themes/01_chixia_fire-fire.png',
  '土火': '/assets/illustration/pair-themes/02_nuanqiu_fire-earth.png',
  // ... 其余映射
};
```

### ⚠️ 包大小注意

微信小程序限制：
- **主包不超过 2MB**
- **整个小程序（含分包）不超过 20MB**

当前插画素材约 **30MB**，超过限制。建议方案：

1. **压缩图片**：用 TinyPNG 等工具压缩到每张 200-300KB，总量可降到 6-8MB
2. **云存储/CDN**：将图片上传到微信云存储或其他 CDN，运行时动态加载（推荐，不占包体积）
3. **分包加载**：将塔罗牌面放到独立分包，按需加载
4. **按需使用**：先只嵌入配对主题背景（10张），塔罗牌面后续再处理

### 作为手绘参考

你是插画师，这些 AI 生成图可以作为：
- 构图参考（人物位置、元素布局、色彩搭配）
- 风格基准（统一水彩质感、星空发光、花卉边框）
- 二次创作底稿（在其基础上修改、重绘、加入个人风格）

建议先画 3 张样张确认最终风格：「恋人」「星星」「太阳」，确认后再批量重绘 22 张。
