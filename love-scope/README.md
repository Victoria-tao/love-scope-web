# 月下签 · 情感运势小程序

一个「星座配对 + 塔罗抽牌」的微信原生小程序，内容仅供娱乐参考。
解读采用**道家 + 星座家双重视角**：融入阴阳二气、五行生克、流年太岁、天干地支（道），以及元素相位、守护星、行星能量（星）。

## 功能

- **灵活测算**：星座 / 属相 / 年份**任意填写一项即可**查看运势
  - 双方星座都填 → 缘分配对（指数 + 五维雷达图 + 完整解读 + 道家论缘）
  - 只填一方星座 → 该星座个人年度情感运
  - 双方属相都填 → 生肖缘分（六合/三合/六冲/六害 + 五行生克）
  - 只填一方属相 → 属相个人年度情感运
  - 选年份（今年/明年）→ 流年情感总运（天干地支 + 12生肖年度主题）
- **塔罗抽牌**：默念问题，抽取 22 张大阿卡纳（单张/三张·过去现在未来），含正逆位解读与情感提示

## 技术方案

- 微信原生小程序（WXML/WXSS/JS），零后端、零云开发，数据全部本地化，可直接运行
- 配对逻辑：基础 50 分 + 按黄道距离相位加分（可复算），星座/属相各 144 种组合全覆盖
- 道/星体系：
  - 星座：道家阴阳（阳/阴）+ 星座元素（火土木水）生克（比和/相生/相成/相冲/相耗）+ 守护星
  - 属相：传统五行（金木水火土）生克 + 六合/三合/六冲/六害
  - 流年：天干地支推算 + 12地支年度情感主题 + 个人五行 vs 流年地支的影响（比和/生扶/相泄/受克/克出）
- 塔罗抽牌：Fisher-Yates 洗牌 + 正逆位随机（纯前端）

## 使用方法

### 1. 导入微信开发者工具

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）
2. 打开工具 → 选择「小程序」→「导入项目」
3. 目录选择本项目文件夹 `love-scope`，AppID 选择「测试号」或填入你自己的 AppID
4. 导入后即可在模拟器预览、真机调试

### 2. 换成自己的 AppID

项目当前 `project.config.json` 中的 `appid` 为 `touristappid`（游客模式）。
在开发者工具「详情 → 基本信息」里替换为你的测试号 AppID 或正式小程序 AppID 即可。

### 3. 绘制并接入塔罗插画（可选，强烈建议）

- 22 张牌面插画放置于 `assets/cards/`，命名见该目录 README
- 替换 `pages/tarot-result/tarot-result.wxml` 中的占位卡片为 `<image>` 引用

## 合规提醒（重要）

- 星座运势、塔罗占卜属于**审核较严格**的内容类目，建议定位为「**情感测试 / 娱乐互动**」，弱化"算命"属性，页面已内置免责声明
- 不做付费诱导、不承诺绝对结果、不涉及时政/医疗
- 个人主体小程序：不支持微信支付/电商，请勿加收费功能；如需商业运营请用企业主体
